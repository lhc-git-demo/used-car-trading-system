# 概要设计

## 1. 总体设计思路
系统采用 B/S 架构，将用户端和管理员端分离，前端使用 Vue 3 构建展示层，后端基于 Spring Boot 提供 REST API，数据库使用 MySQL 存储数据。

## 2. 模块设计
### 2.1 用户模块
负责用户注册、登录、信息维护和个人车源发布。

### 2.2 车辆模块
负责车型分类、车辆信息管理、筛选查询、价格展示等。

### 2.3 留言模块
负责用户与管理员之间的留言咨询功能。

### 2.4 管理模块
负责后台管理、审核、车辆上下架、分类维护、用户管理。

## 3. 数据库设计原则
- 规范化数据库设计
- 主键唯一、外键约束
- 使用时间字段记录创建时间和更新时间
- 方便扩展和维护
